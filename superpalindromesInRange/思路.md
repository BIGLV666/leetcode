# 906. 超级回文数（Hard）

**题目链接**: https://leetcode.cn/problems/super-palindromes/

## 核心思路

**构造回文根** — 直接构造可能的回文数，平方后验证平方值是否也是回文数。

1. 回文数可以由其"半截"种子（seed）通过镜像构造出来。
2. 分别构造奇数长度和偶数长度的回文数作为候选根 root。
3. 计算 `square = root * root`，若 `square` 在 `[left, right]` 范围内且 `square` 自身也是回文数，则计数 +1。
4. 当 `root > right / root` 时停止（等价于 `root * root > right`，用除法避免乘法溢出）。

## 关键函数

- `makePalindrome(seed, odd)`: 将 seed 镜像构造成回文数。odd 为 true 时中间数字不重复。
- `isPalindrome(number)`: 反转数字判断是否回文。

## 复杂度

- **时间复杂度**: O(√⁴R)，其中 R = right。种子的枚举范围大约是 `√R` 的数量级（约 10⁵），每种种子构造回文和验证都是 O(1)。
- **空间复杂度**: O(1)。

## 易错点

1. **乘法溢出**: `root * root` 可能超出 int64 范围，需用除法 `root > right / root` 避免溢出。
2. **奇数/偶数长度**: 遍历 `odd ∈ {true, false}` 确保覆盖所有回文根。
3. **种子范围**: 从 1 开始枚举，直到 `root > right / root` 自动停止。
