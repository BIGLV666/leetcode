# 324. 摆动排序 II（Medium）

**题目链接**: https://leetcode.cn/problems/wiggle-sort-ii/

## 核心思路

**排序 + 交错填充** — 将数组排序后，从大到小交替填入奇偶位置，使每个位置满足 `nums[0] < nums[1] > nums[2] < nums[3] > ...`。

1. 对数组排序，复制一份 `res = sorted(nums)`。
2. 从大到小遍历 `res`，**先填奇数位**（1, 3, 5, ...），**再填偶数位**（0, 2, 4, ...）。
3. 这样保证大数在奇数位（峰值），小数在偶数位（谷值）。

## 为什么先填奇数位再填偶数位？

- 若先填偶数位，可能出现相邻的奇数位和偶数位值相等（如 `[4,5,5,6]` 排序后填偶位 `[4,?,5,?]` 然后填奇位 `[4,5,5,6]` → 相邻相等）。
- 先填奇数位确保大数先占据间距最大的位置，降低相邻相等的风险。

## 复杂度

- **时间复杂度**: O(N log N)，排序开销。
- **空间复杂度**: O(N)，辅助数组 res。

## 更优解法

可做到 O(N) 时间 + O(1) 空间：使用 QuickSelect 找中位数，然后通过虚拟索引（virtual indexing）进行三路划分（荷兰国旗问题）。本实现使用排序法，代码简洁。
