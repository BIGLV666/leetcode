# 2029. 石子游戏 IX（Medium）

**题目链接**: https://leetcode.cn/problems/stone-game-ix/

## 核心思路

**模 3 计数 + 奇偶性分析** — 将石子按模 3 余数分为三类，分析 Alice 的必胜条件。

1. 所有石子价值 mod 3，统计余数 0、1、2 的个数。
2. 核心：余数 0 的石子不影响"当前和 mod 3"，但可以改变回合的奇偶性。
3. 如果 `cnt[0] % 2 == 0`（偶数个 0）：Alice 必胜当且仅当 `cnt[1] > 0` **且** `cnt[2] > 0`（即两种非零余数都存在）。
4. 如果 `cnt[0] % 2 == 1`（奇数个 0）：Alice 必胜当且仅当 `abs(cnt[1] - cnt[2]) > 2`。

## 直觉

- 游戏相当于轮流取石子，当前和的 mod 3 不能为 0。
- 余数 0 的石子相当于"跳过"一步（不改变和的模），但交换了先后手。
- 偶数个 0 不改变先后手，奇数个 0 翻转先后手。

## 复杂度

- **时间复杂度**: O (N)，一次遍历统计。
- **空间复杂度**: O (1)。

## 易错点

1. 返回的是 `!condition` 形式（Alice 必胜 = NOT (Bob 必胜条件)）。
2. 浮点比较 `math.Abs(float64(cnt[1]-cnt[2]))` 可改为整数版本 `abs(cnt[1] - cnt[2])` 更安全。
