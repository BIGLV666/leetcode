# 164. 最大间距（Hard）

**题目链接**: https://leetcode.cn/problems/maximum-gap/

## 核心思路

桶排序 / 鸽巢原理。排序后相邻两数的最大差，不需要真的把数组排出来：

设数组最小值 `min`、最大值 `max`、长度 `n`。鸽巢原理保证：**最大间距 ≥ d = ceil((max - min) / (n - 1))**（n-1 个间隙平分 max-min，至少一个不小于平均值）。

取宽度为 d 的桶装元素。**同一桶内任意两个元素的差必然小于 d**，而答案 ≥ d——所以桶内差永远不可能是答案，根本不用比较。只需记录每个桶的最小值和最大值，答案一定是某个非空桶的最小值减去它前一个非空桶的最大值。这样就把「排序 O(n log n)」降到了 O(n)。

## 算法流程

1. 扫描得 `min`、`max`；若 `max - min <= 1`，答案就是它本身（同时覆盖了全相等、单元素等退化情形）。
2. 计算 `d = ceil((max - min) / (n - 1))`，桶数 `size = (max - min) / d + 1`。
3. 每个元素按 `idx = (x - min) / d` 入桶，只维护桶内 min/max。
4. 从左到右扫描桶，对每个非空桶算 `本桶 min - 前一非空桶 max`，取最大值。

## 正确性说明

- 鸽巢给出答案 ≥ d，桶内差 < d（桶宽为 d 且端点错开），故跨桶差才可能成为答案。
- 相邻两个排序后元素若在不同桶，其差 = 「后桶的某个 min - 前桶的某个 max」≤ 扫描时算出的对应差；扫描取遍所有相邻非空桶对，不漏。
- `max - min <= 1` 时直接返回是正确的：间距只可能是 0 或 1。

## 复杂度

时间 O(n)（三次线性扫描），空间 O(n)（桶）。满足题目"线性时间和空间"的进阶要求。

## 易错点

- **别忘退化分支**：`max - min <= 1` 时答案直接是 `max - min`，否则 `n - 1` 参与计算 `d` 时逻辑虽然对，但全相等 / 单元素时会走进无意义的桶扫描（本题实现里靠这条分支同时处理掉了 n = 1 与全相等）。
- `d` 要用**向上取整**：`(max - min + n - 2) / (n - 1)`。写成向下取整会让桶宽偏小、桶内差可能 ≥ d，破坏"桶内不用比较"的不变量。
- 桶下标用 `(x - min) / d`，最大元素恰好落在最后一个桶（`size - 1`），不会越界——前提是 `size` 按 `(max - min) / d + 1` 算。
- 答案的初始化与"前一非空桶"哨兵要处理好：第一个非空桶不计算差值（实现里把 preMax 置成极大值，第一轮 `bucketMin - preMax` 必为负、被 max(0, …) 吸收掉）。
