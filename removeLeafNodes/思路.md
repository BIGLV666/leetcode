# 1325. 删除给定值的叶子节点

## 题目描述

给你一棵二叉树和一个整数 `target`，删除所有值为 `target` 的叶子节点。

注意：删除叶子节点后，如果它的父节点变成了新的叶子节点，并且父节点的值也等于 `target`，那么父节点也需要被删除。这个过程持续进行，直到没有符合条件的叶子节点为止。

题目链接：[1325. 删除给定值的叶子节点](https://leetcode.cn/problems/delete-leaves-with-a-given-value/description/)

### 示例

```text
输入：root = [1,2,3,2,null,2,4], target = 2
输出：[1,null,3,null,4]
```

对应的树结构如下：

```text
        1
       / \
      2   3
     /   / \
    2   2   4
```

删除过程：

1. 删除最底层值为 `2` 的叶子节点。
2. 原来左侧的 `2` 变成叶子节点，继续删除。
3. `3` 左侧值为 `2` 的叶子节点也被删除。
4. 最终得到 `[1,null,3,null,4]`。

---

## 思路

删除一个叶子节点后，它的父节点可能会变成新的叶子节点，因此处理顺序必须是：

```text
子节点 -> 父节点 -> 更高层父节点 -> 根节点
```

这本质上是一个自底向上的过程。常见的做法是使用 DFS 后序遍历，但本题采用 BFS 实现：

1. 使用 BFS 遍历整棵树，按层收集所有节点。
2. 记录每个节点的父节点。
3. 逆序遍历 BFS 收集的节点列表。
4. 逆序时子节点一定先于父节点，因此可以模拟后序处理。
5. 如果当前节点是目标值叶子节点，直接修改父节点的 `left` 或 `right` 引用。

### 为什么 BFS 逆序可以实现自底向上？

BFS 的层序遍历满足：

```text
父节点一定出现在子节点之前
```

例如：

```text
        1
       /
      2
     /
    2
```

BFS 顺序是：

```text
[1, 2, 2]
```

逆序后是：

```text
[2, 2, 1]
```

因此最底层节点会先处理。删除最底层节点后，中间节点可能变成叶子节点，随后也会被正确处理。

## 算法流程

### 1. 处理空树

如果根节点为空，直接返回 `null`：

```java
if (root == null) {
    return null;
}
```

### 2. BFS 收集节点并记录父节点

使用三个辅助结构：

- `queue`：BFS 队列。
- `nodes`：保存 BFS 遍历得到的节点顺序。
- `parents`：保存“子节点 -> 父节点”的映射。

根节点没有父节点：

```java
parents.put(root, null);
```

遍历每个节点时，将其左右孩子加入队列，并记录父节点：

```java
if (node.left != null) {
    parents.put(node.left, node);
    queue.offer(node.left);
}

if (node.right != null) {
    parents.put(node.right, node);
    queue.offer(node.right);
}
```

### 3. 逆序处理节点

从 `nodes` 的末尾向前遍历：

```java
for (int i = nodes.size() - 1; i >= 0; i--) {
    TreeNode node = nodes.get(i);
}
```

当前节点只有同时满足以下条件才删除：

```java
node.val == target
node.left == null
node.right == null
```

可以合并写成：

```java
if (node.val != target || node.left != null || node.right != null) {
    continue;
}
```

### 4. 修改父节点引用

如果当前节点没有父节点，说明当前节点就是根节点：

```java
if (parent == null) {
    return null;
}
```

否则通过引用判断当前节点是左孩子还是右孩子：

```java
if (parent.left == node) {
    parent.left = null;
} else {
    parent.right = null;
}
```

这里必须使用 `==` 比较对象引用，而不能比较节点值。因为树中可能存在多个值相同的节点。

## 正确性分析

### 1. BFS 会访问所有节点

从根节点开始，BFS 会将每个非空左孩子和右孩子加入队列，因此每个树节点都会被访问一次，并保存到 `nodes` 中。

### 2. 逆序保证子节点先于父节点

在 BFS 顺序中，父节点一定先于子节点出现。因此逆序遍历后，子节点一定先于父节点处理。

这保证了：当处理父节点时，它的子节点是否已经被删除是确定的。

### 3. 删除条件完全符合题意

只有当节点值等于 `target` 且左右孩子都为空时，才会删除节点。因此：

- 值不等于 `target` 的节点不会被删除。
- 仍然拥有子节点的非叶子节点不会被删除。
- 删除子节点后新产生的叶子节点可以被继续判断。

### 4. 级联删除能够正确进行

删除子节点时，直接把父节点对应的引用设置为 `null`。如果父节点的另一个孩子本来也是空，那么父节点就会变成叶子节点。

由于父节点在逆序列表中还没有处理，所以它随后会按照最新的左右孩子状态进行判断，从而实现级联删除。

### 5. 根节点可以被正确处理

如果根节点本身是值为 `target` 的叶子节点，它在逆序处理时没有父节点，因此直接返回 `null` 即可。

## Java 代码

```java
class Solution {
    public TreeNode removeLeafNodes(TreeNode root, int target) {
        if (root == null) {
            return null;
        }

        List<TreeNode> nodes = new ArrayList<>();
        Map<TreeNode, TreeNode> parents = new HashMap<>();
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        parents.put(root, null);

        // BFS 收集节点，并建立“子节点 -> 父节点”的映射。
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            nodes.add(node);

            if (node.left != null) {
                parents.put(node.left, node);
                queue.offer(node.left);
            }
            if (node.right != null) {
                parents.put(node.right, node);
                queue.offer(node.right);
            }
        }

        // 逆序处理，保证子节点先于父节点。
        for (int i = nodes.size() - 1; i >= 0; i--) {
            TreeNode node = nodes.get(i);
            if (node.val != target || node.left != null || node.right != null) {
                continue;
            }

            TreeNode parent = parents.get(node);
            if (parent == null) {
                return null;
            }

            if (parent.left == node) {
                parent.left = null;
            } else {
                parent.right = null;
            }
        }

        return root;
    }
}
```

## 复杂度分析

设二叉树中有 `n` 个节点。

### 时间复杂度

- BFS 遍历每个节点一次：`O(n)`。
- 逆序遍历 `nodes` 一次：`O(n)`。
- 哈希表的查询和插入平均为 `O(1)`。

因此总时间复杂度为：

```text
O(n)
```

### 空间复杂度

- `nodes` 最多保存 `n` 个节点。
- `parents` 最多保存 `n` 条父子关系。
- `queue` 最多保存 `n` 个节点。

因此额外空间复杂度为：

```text
O(n)
```

## 为什么不需要反复 BFS？

一种直观方法是不断执行：

```text
寻找当前叶子节点 -> 删除叶子节点 -> 再次遍历整棵树
```

这种方法可能需要多轮遍历，最坏时间复杂度会达到 `O(n^2)`。

本题提前使用 BFS 确定所有节点的父子关系和处理顺序，再通过逆序遍历完成自底向上的删除，因此只需要：

```text
一次 BFS + 一次逆序遍历
```

最终复杂度为：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

## 易错点

### 1. 不能只按 BFS 顺序直接删除

BFS 是从上到下处理的。处理父节点时，子节点可能还没有被删除，因此父节点是否为叶子节点无法确定。

必须逆序处理 BFS 结果。

### 2. 删除节点要修改父节点引用

仅仅给节点赋一个特殊值，并不是真正从树中删除。正确做法是：

```java
parent.left = null;
```

或：

```java
parent.right = null;
```

### 3. 不能用节点值判断左右孩子

错误示例：

```java
if (parent.val == node.val) {
    // 错误，无法判断 node 是左孩子还是右孩子
}
```

正确做法是比较引用：

```java
if (parent.left == node) {
    parent.left = null;
} else {
    parent.right = null;
}
```

### 4. 根节点需要单独处理

根节点没有父节点。如果根节点被删除，结果应该是空树：

```java
return null;
```

---

## 总结

本题的核心是处理“删除叶子后产生新叶子”的级联关系。

虽然使用的是 BFS，但通过保存 BFS 顺序并逆序处理，可以得到自底向上的处理顺序。

核心步骤可以概括为：

```text
BFS 收集节点
记录父节点
逆序处理节点
直接断开父节点引用
```

这种方法避免了反复遍历整棵树，时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。
