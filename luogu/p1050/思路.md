# 洛谷 P1050 循环

**题目链接**: https://www.luogu.com.cn/problem/P1050

## 核心思路

**分解模数 + 乘法阶** — 要求最小的正整数 `L`，使 `10^k | n^(L+1) - n`。因为 `10^k = 2^k * 5^k` 且两个模数互质，可以对 `p ∈ {2, 5}` 分别讨论，再取两组周期的最小公倍数。

记 `s_p` 为素数 `p` 在 `n` 中的指数（`p^e | n` 的最大 `e`），并注意

```text
n^(L+1) - n = n * (n^L - 1)
```

当 `s_p > 0` 时，`n^L - 1` 与 `p` 互质，所以上式对 `p` 的估值恰为 `s_p`，与 `L` 无关：

- **0 < s_p < k**：无论 `L` 取何值，`p^k` 都整除不了，答案不存在，输出 `-1`。
- **s_2 ≥ k 且 s_5 ≥ k**：`10^k | n`，所有幂同余 0，最小 `L = 1`。
- **s_p = 0**：条件退化为 `n^L ≡ 1 (mod p^k)`，即 `L` 必须是 `n` 在模 `p^k` 下的乘法阶的倍数。

## 算法流程

```text
s2 = v_2(n), s5 = v_5(n)
if (0 < s2 < k) 或 (0 < s5 < k): 输出 -1
answer = 1
if s2 == 0: answer = lcm(answer, ord_{2^k}(n))
if s5 == 0: answer = lcm(answer, ord_{5^k}(n))
输出 answer
```

求阶用群指数做上界逐次约分：`2^k` 的群指数是 `φ(2^k) = 2^(k-1)`，`5^k` 的是 `φ(5^k) = 4 * 5^(k-1)`；两者都只含素因子 `2`、`5`，因此只需反复试除这两个因子，能约掉就约掉，剩下的就是最小指数。

## 正确性说明

- 合法解集合恰好是「`L` 同时是 `ord_{2^k}(n)` 与 `ord_{5^k}(n)` 的倍数」（当对应 `s_p = 0` 时），由中国剩余定理，这等价于 `L` 是两者最小公倍数的倍数，故取 `lcm` 即为最小解。
- 估值论证保证前两类判定既不漏也不多：`v_p(n^(L+1) - n) = s_p` 与 `L` 无关，所以只要 `0 < s_p < k` 就永远无解。
- 只有 `s_p = 0` 的素因子才需要继续处理；`s_p ≥ k` 的那一侧模数自动满足，不需要进入求阶分支。

## 复杂度

- 时间复杂度：求阶的候选指数只含因子 `2` 和 `5`，试除次数为 `O(k)`；每次判定是一次大整数模幂，整体为 `O(k log k)` 级别的 `BigInteger` 运算。
- 空间复杂度：`O(1)` 个大整数变量（数值本身可达 `10^k` 位数级别的中间幂）。

## 易错点

- `10^k` 不能整体处理，必须拆成互质的 `2^k` 与 `5^k` 分别求周期再取最小公倍数。
- 判定顺序不能颠倒：先判 `0 < s_p < k` 的无解情况，再处理 `s_p ≥ k`（答案为 1）与 `s_p = 0`（求阶）。
- 求阶时直接枚举 `1..φ` 会超时，必须用「群指数逐步约分」的写法。
- 中间结果远超 `long`，全程使用 `BigInteger`。
