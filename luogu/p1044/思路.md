# 洛谷 P1044 栈

**题目链接**: https://www.luogu.com.cn/problem/P1044

## 核心思路

**Catalan 数递推** — 入栈、出栈的过程与长度为 `n` 的合法括号序列一一对应：进栈看作 `(`，出栈看作 `)`，任意前缀中出栈次数不超过进栈次数。因此答案就是第 `n` 个 Catalan 数，用单项递推直接计算，不需要枚举所有出入栈序列。

递推式为 `C(0) = 1`，`C(n) = C(n-1) * (4n-2) / (n+1)`；也可以按卷积形式 `C(n) = Σ C(i) * C(n-1-i)` 计算。

## 算法流程

```text
result = 1
for i in 1..n:
    result = result * (4i - 2) / (i + 1)
输出 result
```

## 复杂度

- 时间复杂度：`O(n)`，一次循环即可。
- 空间复杂度：`O(1)`，只保存一个累乘变量（`n ≤ 18` 时结果在 `long` 范围内）。

## 易错点

- 必须先乘后除：写成 `result * ((4i-2)/(i+1))` 会因整数除法丢精度。
- 中间结果一定是整数，但要用 `long` 累乘，避免 `int` 溢出。
