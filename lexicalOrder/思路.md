# 思路

> 你选用何种方法解题？

**字典序 10 叉树上的先序遍历**——题目要求 O(n) 时间、O(1) 额外空间,排序法(O(n log n)+O(n))直接出局,必须"按顺序生成"而非"生成后排序"。

把 [1, n] 的数字按字典序组织成一棵 **10 叉前缀树**:

- 第一层(根)是 `1..9`;
- 节点 `cur` 的孩子是 `cur*10 + 0` 到 `cur*10 + 9`(即尾部追加一个数字);
- **先序遍历这棵树、跳过超过 n 的节点,得到的就是字典序序列**——因为同一前缀下,"追加更小数字"的整棵子树都排在"追加更大数字"之前,这正是先序"一路向左深入"的性质。

以 `n = 13` 为例(✓ = ≤13 会输出;✗ = 超界被剪掉):

```text
            1✓ ─────┬──── 2✓ ─── 3✓ ── 4✓ ... ── 9✓      (根层 1..9)
        ┌───┼───┐
       10✓ 11✓ 12✓ 13✓ ─── 14✗(同一层还有 15..19 全 ✗)
      ┌─┴─┐
    100✗ 101✗ ... (13 之后 10x 全超界)
```

先序遍历序列:`1 → [10 → (100..109 全✗) → 11 → 12 → 13] → 2 → 3 → ... → 9`
= `[1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9]` ✓ 与示例一致。

两种实现走同一棵树:

| 实现 | 机制 | 额外空间 |
|------|------|----------|
| ① 迭代游走(主解) | 用 `j` 直接记录"当前树节点",手算先序的**下一个**节点 | O(1) |
| ② 递归先序 | 显式递归树遍历,自然回溯 | O(log n) 栈 |

# 解题过程

> 这些方法具体怎么运用？

## 方法①:迭代游走(满足 O(1) 空间的主解)

不动递归栈,直接维护"当前节点编号" `j`,循环 n 次,每次 O(1) 算出**先序遍历的下一个节点**:

1. **深入优先**:`j * 10 <= n` 时,先序下一个节点是 `j * 10`(追加一个 0,即走进第一个孩子)。
   例:`1 → 10 → 100`(只要不越界就一路左下)。
2. **深入失败则找右兄弟**:先不断 `j /= 10` 回退,直到当前节点"个位不是 9 且 `j+1 <= n`";
   然后 `j++` 移到下一个兄弟。
   - `j % 10 == 9` 表示当前是本层最右孩子,没有右兄弟,必须向上回退;
   - `j + 1 > n` 表示右兄弟超出 n,同样回退。

`n = 13` 时从 13 走到 2 的完整回退过程(体现"回退到祖先再 ++"的语义):

```text
j=13: 个位 3≠9 但 13+1=14 > 13 → 13/10=1   (回退到 1)
j=1 : 个位 1≠9 且 1+1=2 ≤ 13   → j=2      (1 的下一个兄弟 2)✓
```

再看 `n=100` 时 `j=100` 的下一步:

```text
j=100: 1000 > 100 深入失败;100%10==0≠9 但 101 ≤ 100?否 → 100/10=10
j=10 : 100 > 100 深入失败;10%10==0 但 11 ≤ 100?是 → j=11 ✓
```

即 100 之后是 101——与真实字典序一致(100, 101, ..., 109, 11, 12, ..., 99, 100 中的 100 在 99 之后)。

### 迭代游走的"隐式递归栈"

方法①本质上是用 `j /= 10` 模拟递归回退。以 `n=110`、走到 109 为例,两种视角对照:

```text
显式递归栈(方法②)             迭代游走(方法①)等效状态
┌─────────────┐
│ dfs(1)      │ ← 栈底          j=109
│ dfs(10)     │                 10*10=100≤110?深入得 100<109 已访问 → 走 101
│ dfs(109)    │ ← 栈顶          109 的下一个:109%10=9 → 109/10=10 → 10+1=11
└─────────────┘                 等效于:弹栈 dfs(109)→dfs(10),转向兄弟 11
   回退 = j/=10
   前进 = j++  /  j*=10
```

`j /= 10` 一次就等于弹一层栈帧;连续 `%10==9` 对应连续弹栈到"还有右兄弟的祖先"。

## 方法②:递归先序(直观对照版)

```java
void dfs(int cur, int n, List<Integer> out) {
    if (cur > n) return;
    out.add(cur);                    // 先序:先输出自己
    for (int i = 0; i <= 9; i++) {   // 孩子:cur*10 + 0..9
        dfs(cur * 10 + i, n, out);
    }
}
// 根循环:for (int root = 1; root <= 9 && root <= n; root++) dfs(root, n, out);
```

**⚠️ 高频 bug:孩子循环必须从 0 开始(`i <= 9`),不能想当然写成 1..9**——
`cur*10 + 0` 正是 `10、100、1000` 这类整十/整百节点,漏掉 0 会导致 n=13 输出丢 10
(变成 `[1,11,12,13,2,...]`),且因为绝大多数用例仍正确,这类错误很难靠肉眼发现。
(本项目初始版本就踩了这个坑,已被随机对拍抓出。)

递归深度 = 数的位数 = O(log₁₀ n),对 n ≤ 5×10⁴ 仅 5 层,栈开销可忽略;但严格按题意 O(1) 空间时选迭代版。

# 复杂度

- 时间复杂度: $O(n)$ —— 每个输出恰好一步;迭代版游走均摊 O(1)(回退次数合计 ≤ 深入次数),递归版访问节点 ≤ 10n。
- 空间复杂度: ① 迭代 $O(1)$;② 递归 $O(\log_{10} n)$ 栈深。

# 易错点

1. **孩子从 0 开始**:`cur*10+0` 是 10/100/1000,循环写 `1..9` 必丢节点(见上)。
2. **迭代版回退条件**:`j % 10 == 9 || j + 1 > n` 两个条件缺一不可——前者是"没有右兄弟",后者是"右兄弟越界"。
3. **循环恰好 n 次**:迭代版 `for i in [0, n)` 按输出个数驱动,天然覆盖所有节点,不需要显式判断结束。
4. **字典序 ≠ 数值序**:`100 < 11 < 2` 在字典序下成立,别用数值比较器偷懒(排序法还会超空间要求)。

# Code

## 迭代游走(O(1) 空间,主解)

```Java []
class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> res = new ArrayList<>();
        int j = 1;
        for (int i = 0; i < n; i++) {   // 恰好收集 n 个数
            res.add(j);
            if (j * 10 <= n) {
                j *= 10;                 // 深入:优先走向第一个孩子(追加 0)
            } else {
                // 走不通:不断回退到"个位不是 9 且 ++ 后不越界"的祖先
                while (j % 10 == 9 || j + 1 > n) {
                    j /= 10;
                }
                j++;                     // 移动到下一个兄弟
            }
        }
        return res;
    }
}
```

## 递归先序(直观对照)

```Java []
class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> res = new ArrayList<>();
        for (int root = 1; root <= 9 && root <= n; root++) {
            dfs(root, n, res);
        }
        return res;
    }

    private void dfs(int cur, int n, List<Integer> out) {
        if (cur > n) return;
        out.add(cur);
        int base = cur * 10;
        for (int i = 0; i <= 9; i++) {  // 0..9:cur*10+0 正是 10/100 这类节点
            dfs(base + i, n, out);
        }
    }
}
```
