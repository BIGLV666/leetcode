# 思路

> 你选用何种方法解题？

**单栈归约(表达式求值的经典套路)**。

表达式的嵌套结构天然对应栈:每个 `op(...)` 子表达式在遇到 `)` 时,它的全部参数都恰好压在栈中、且位于本层 `(` 之上。因此:

- 遇到 `t`、`f`、`&`、`|`、`!`、`(` 一律入栈(逗号跳过);
- 遇到 `)` 时完成一次**归约**:弹出参数 → 取出本层运算符 → 按语义求值 → 把子结果以 `t`/`f` 形式回栈,当作外层的普通操作数。

一层层 `)` 归约下去,栈最终只剩一个字符,即整个表达式的值。

求值语义的三行总结:

| 运算符 | 语义 | 一行实现 |
|--------|------|----------|
| `&(...)` | 全真才真 | `!args.contains(false)` |
| `\|(...)` | 有真即真 | `args.contains(true)` |
| `!(x)` | 取反(恰一个参数) | `!args.iterator().next()` |

# 解题过程

> 这些方法具体怎么运用？

1. **扫描入栈**:遍历表达式,逗号 `,` 无信息量直接跳过;其余字符(`t/f/&/|/!/(`)全部入栈。
2. **归约** `)`:遇到 `)` 时,栈顶往下到本层 `(` 之间的所有字符就是本层参数——把它们弹出并收集成 `Set<Boolean>`(顺序无关:`&`、`|` 满足交换/结合律,用 Set 还自动去重)。
3. **取运算符**:先 `pop()` 丢弃本层 `(`,再 `pop()` 得到紧邻其下的运算符——**括号与运算符的弹出顺序不能反**。
4. **回填子结果**:求值结果 `res` 转成 `'t'`/`'f'` 压回栈顶,作为外层表达式的操作数参与后续归约。
5. **返回**:扫描结束后,栈中唯一剩下的字符就是整个表达式的值。

# 易错点

1. **参数收集的终止条件必须停在 `'('` 上**。如果只排除 `& | !` 三个运算符,`(` 会被当成 `false` 混进参数集合,`&( ... )` 遇到任意一个混入的 `false` 就全错——而且这种错误在"恰好所有子表达式为 false"的用例上**完全看不出来**,必须用随机表达式对拍才能暴露。
2. **弹出顺序**:先丢 `(` 再取运算符;取反了 `switch` 会拿到 `'('` 直接失败。
3. **`!` 恰有一个参数**(题目保证),所以取 `args` 中唯一元素取反即可;若 `args` 收集时混入了假参数,`Set` 的迭代顺序会导致结果不稳定。
4. **不要用跨表达式的公共 `result` 变量累算**——内层结果会残留到外层,只能靠 `&`/`|` 的交换律"歪打正着",这是把简单问题写复杂的常见根源。

# 复杂度

- 时间复杂度: $O(n)$ —— 每个字符至多入栈、出栈各一次。
- 空间复杂度: $O(n)$ —— 栈深与表达式嵌套层级成正比。

# Code

```Java []
class Solution {
    public boolean parseBoolExpr(String expression) {
        Deque<Character> st = new ArrayDeque<>();
        for (char c : expression.toCharArray()) {
            if (c == ',') continue;
            if (c != ')') {
                st.push(c);
                continue;
            }   // 运算符/操作数/'(' 直接入栈
            Set<Boolean> args = new HashSet<>();       // 收集本层参数,顺序无关
            while (st.peek() != '(') {                 // 参数都在本层 '(' 之上,遇到即停
                args.add(st.pop() == 't');
            }
            st.pop();                                  // 丢弃本层 '('
            char op = st.pop();                        // 运算符紧邻 '(' 之下
            boolean res = switch (op) {
                case '&' -> !args.contains(false);     // 全真才真
                case '|' -> args.contains(true);       // 有真即真
                default -> !args.iterator().next();   // '!' 恰一个参数
            };
            st.push(res ? 't' : 'f');                  // 子结果回栈当操作数
        }
        return st.pop() == 't';
    }
}
```
