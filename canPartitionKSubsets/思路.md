# 698. 划分为 K 个相等的子集（Medium）

**题目链接**: https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/

## 当前实现（贪心配对法）

本实现使用哈希表贪心匹配：对于数组中的每个元素，检查是否存在补数使它们的和等于 target（sum/k）。若存在则配对删除，否则将元素自身加入哈希表。

**注意**: 此贪心方法仅适用于某些特例（如 k=2 时等价于划分等和子集问题），对于一般情况可能不适用。标准解法应使用**回溯 + 剪枝**。

## 标准解法思路（回溯 + 剪枝）

1. 计算总和 sum，若 sum % k ≠ 0 直接返回 false。
2. 将数组从大到小排序（优先放大的，减少回溯分支）。
3. 回溯：将元素逐个尝试放入 k 个桶中，每个桶容量为 target = sum / k。
4. 剪枝：若当前桶装不下则跳过；若当前桶与上一个桶容量相同且上一个桶已失败，则跳过。

## 复杂度

- 贪心法: O(N)，一次遍历。
- 回溯法: O(k^N)，但剪枝后实际运行很快。
