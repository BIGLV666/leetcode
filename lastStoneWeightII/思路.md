# 1049. 最后一块石头的重量 II（Medium）

**题目链接**: https://leetcode.cn/problems/last-stone-weight-ii/

## 核心思路

**0/1 背包问题转换** — 将问题转化为：将石头分成两堆，使两堆重量差最小。

1. 总重量 sum，目标：找到不超过 sum/2 的最大子集和。
2. 最终答案 = sum - 2 × 最大子集和（即两堆之间的最小差值）。
3. 使用布尔型 DP 数组：`dp[j]` 表示能否凑出重量 j。
4. 状态转移：`dp[j] = dp[j] || dp[j - weight]`（逆序枚举 j）。

## 复杂度

- **时间复杂度**: O (N × M)，N 为石头数量，M = sum/2。
- **空间复杂度**: O (M)，一维 DP 数组。

## 易错点

1. 外层循环枚举石头，内层循环枚举重量（逆序，避免重复使用同一石头）。
2. 结果从 `m = sum/2` 向下找第一个可达的 dp[j]，答案 = sum - 2j。
3. Java 中 for 循环 `for (int j = m;; --j)` 缺少终止条件，依靠 `if (dp[j])` 中的 return 退出。
