# 1401. 圆和矩形是否有重叠

## 题目描述

给你一个圆(半径 `radius`,圆心 `(xCenter, yCenter)`)和一个轴对齐矩形
(左下角 `(x1, y1)`,右上角 `(x2, y2)`,保证 `x1 < x2`、`y1 < y2`)。

如果圆和矩形**有重叠**(边界相切也算重叠),返回 `true`,否则返回 `false`。

题目链接:[1401. 圆和矩形是否有重叠](https://leetcode.cn/problems/circle-and-rectangle-overlapping/)

### 示例

```text
输入:radius = 1, xCenter = 0, yCenter = 0, x1 = 1, y1 = -1, x2 = 3, y2 = 1
输出:true
```

圆的右边缘 `x = 1` 与矩形的左边缘 `x = 1` 相切,判为重叠。

```text
输入:radius = 1, xCenter = 1, yCenter = 1, x1 = 1, y1 = -3, x2 = 2, y2 = -1
输出:false
```

圆心在矩形上方,距离最近的矩形角点 `(1, -1)` 的距离为 2 > 1,不重叠。

---

## 思路

这题有两条路线,题解用的是路线 B,测试里用路线 A 做参考实现互验。

### 路线 A:最近点法(clamp)

圆与矩形(闭集)相交 ⟺ **圆心到矩形的最近点距离 ≤ 半径**。

最近点的求法:把圆心坐标逐维 clamp 进矩形范围:

```text
cx = min(max(xCenter, x1), x2)
cy = min(max(yCenter, y1), y2)
```

- 圆心在矩形内:clamp 后仍是圆心本身,距离 0 ≤ r ✓
- 圆心在矩形外:clamp 得到矩形边界上离圆心最近的那个点

然后比较 `dx² + dy² <= r²`(用平方比较,避免开方)。全程整数运算,没有浮点误差。

### 路线 B:边线弦法(题解的实现)

**圆心在矩形内 → 必然相交**。这个情形要先单独判:圆可能整个缩在矩形内部,
与四条边都不相交,靠下面的边检测会漏。

圆心在矩形外时,圆与矩形相交 ⟺ **圆与矩形的某条边(线段)相交**。

对每条边所在的直线,计算圆在这条直线上的**弦**:

- 直线 `x = p` 与圆的交点满足 `(p - xc)² + (y - yc)² = r²`,
  解得 `y = yc ± sqrt(r² - (p - xc)²)`,即弦是区间 `[yc - t, yc + t]`,`t = sqrt(r² - d²)`;
- 若 `|p - xc| > r`,直线与圆没有交点,返回一个「不可能与任何区间重叠」的退化区间
  ——这一步**必须先判**,否则 `sqrt` 收到负数得到 `NaN`,转 `int` 会变成垃圾值。

弦与矩形边线段(在另一维上正好是 `[y1, y2]` 这个区间)相交 ⟺ 两个区间相交。

四条边只要有一条相交,答案就是 `true`。

### 为什么「边线弦法」是完备的?

若圆与闭矩形相交且圆心在矩形外,取交集中任意一点 P:连接圆心与 P 的线段
整体落在圆内,而它从矩形外走到矩形内,**必然穿过矩形的边界**,交点 Q 既在圆内又在边上,
即圆与某条边相交。

所以「圆心在矩形内」∨「圆与某条边相交」恰好覆盖所有相交情形,既不漏也不多。

---

## 算法流程

```text
① 圆心在矩形内?                    → true
② 对每条边(左/右/下/上):
     d = 边线坐标 - 圆心对应坐标
     |d| > r?                       → 该边与圆无交,跳过
     t = sqrt(r² - d²)              → 弦的半长
     弦区间与边的区间相交?          → true
③ 四条边都不相交                    → false
```

---

## 整数截断为什么不丢正确性?

`t = sqrt(r² - d²)` 大多是无理数,而题解里用 `int(...)` 把它**向下截断**成整数,
弦区间会稍微变小。这看起来有风险,但对本题是安全的:

- 矩形坐标、圆心坐标、半径全是**整数**;
- 「弦 `[yc - t, yc + t]` 与整数区间 `[y1, y2]` 相交」只取决于整数阈值,例如
  `y1 <= yc + t` ⟺ `y1 - yc <= t`,而 `y1 - yc` 是整数,
  所以 `y1 - yc <= t` ⟺ `y1 - yc <= floor(t)`;
- 也就是说,截断到 `floor(t)` 之后,整数区间与弦是否相交的判断结果**完全不变**。

测试里 `radius = 100000` 的大数用例(如 `r² - d² = 10^10`)也覆盖了这一点。

---

## 正确性分析

1. **层与层互斥**:圆心在矩形内直接返回,剩下的情形都保证圆心在矩形外;
2. **边的枚举完备**:矩形边界由 4 条线段组成,圆与边界相交当且仅当与其中某条相交;
3. **弦区间正确**:勾股定理直接推出,`|d| > r` 时无交点已单独排除;
4. **相切算重叠**:区间比较用的是闭区间(`<=`),切点会被算作相交。

---

## 复杂度分析

- 时间:`O(1)` —— 固定 4 条边,每条边常数次运算;
- 空间:`O(1)`。

路线 A(clamp)同样是 `O(1)`,而且不需要浮点运算,但会引入平方比较;
两条路线的结论在测试里互相验证(20 万组随机用例)。

---

## 易错点

### 1. 圆心在矩形内的情形

圆可能整个缩在矩形内部,与四条边都不相交。不先判「圆心在矩形内」,
边线弦法会错误地返回 `false`。

### 2. `sqrt` 收到负数

`|d| > r` 时 `r² - d² < 0`,`math.Sqrt` 返回 `NaN`,`int(NaN)` 是垃圾值,
可能恰好落进区间里造成误判。必须先判 `|d| > r` 再开方。

### 3. 相切也算重叠

题目把「边界相切」也算重叠,所有比较都要用 `<=`(闭区间),不能用 `<`。

### 4. 平方溢出

坐标可达 `±10^9`,但参与乘方的只有 `radius` 与差值 `d`(`|d| <= 10^9` 时
`r² - d²` 的上界由 `r` 决定),Go 的 `int` 是 64 位,`r <= 10^5` 时
`r² = 10^10` 也在范围内。若把坐标也平方比较(路线 A 的 `dx² + dy²`),
`10^9` 的平方是 `10^18`,仍在 int64 范围内,但已经接近上限,要留意。

## 总结

```text
圆心在矩形内? ── 是 → true
     │ 否
     ▼
对 4 条边:求圆在该边直线上的弦 → 弦与边线段相交? ── 是 → true
     │ 否
     ▼
false
```

本题的「Hard」主要体现在边界情形多:**圆心在矩形内、相切、`sqrt` 负数、整数截断**。
参考实现(clamp 最近点)只有几行,但必须想清楚「闭集相交、相切也算」这个前提。
