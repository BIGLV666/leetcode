# 思路

> 你选用何种方法解题？

两个解法:**位路径递归(主解,无队列)** 和 **经典队列版**。核心都来自完全二叉树的同一个性质——

## 层序编号:完全二叉树的"GPS 坐标系"

完全二叉树按层序从 **1** 开始编号,孩子与父节点的编号关系是纯算术:

```text
            1
          /   \
         2     3
        / \   / \
       4   5 6   7
      /|\
     8 9 ...
```

| 关系 | 公式 | 例子 |
|------|------|------|
| 节点 k 的左孩子 | `2k` | 2 → 4,3 → 6 |
| 节点 k 的右孩子 | `2k+1` | 2 → 5,3 → 7 |
| 节点 k 的父节点 | `k / 2`(整除) | 4→2,5→2,6→3,7→3 |

**为什么?** 编号就是层序顺序:第 k 个节点画完,它的两个孩子必然是全局第 2k、第 2k+1 个被画出的位置(中间没有别的节点插队——完全二叉树逐层从左到右填满)。

这个性质直接解掉本题:若当前树有 `size` 个节点,**新插入的节点编号就是 `size+1`,它的父节点编号就是 `(size+1)/2`**。"找插入位置"从"遍历树"降维成"算一个除法"。

## 方法①:位路径递归(主解,无队列)

### insert 的三步

```text
size = 12,insert(99):
① size++ → 13                 新节点编号 13
② parent = find(13 / 2) = find(6)   父编号 = 新编号/2
③ 13 % 2 == 1 → 奇数 → 挂到节点 6 的右边
```

- 新编号偶数 → 是父的**左**孩子;奇数 → 是父的**右**孩子(编号 2k 必是左,2k+1 必是右)。

### find(k):沿着 k 的二进制位从根走下来

把 k 写成二进制,**最高位恒为 1(就是根),后面每一位是路标:0 走左、1 走右**。

```text
k = 13 = 1101₂
根 = 1(最高位,跳过)
路标 1 → 走右:  1 → 3     (13/2=6? 等价视角:3 = 1*2+1)
路标 0 → 走左:  3 → 6     (6 = 3*2+0)
路标 1 → 走右:  6 → 13    (13 = 6*2+1)
```

递归实现(每层只做一件事:**先拿到父节点,再看我是它的左孩子还是右孩子**):

```text
find(13)
└─ 需要 find(6)
   └─ 需要 find(3)
      └─ 需要 find(1)
         └─ k==1 → return root          ← 触底,开始逐层返回
      return root.right   = 节点 3      ← find(3): 3 奇 → 父(根)的右
   return 节点3.left    = 节点 6        ← find(6): 6 偶 → 父(节点3)的左
return 节点6.right   = 节点 13          ← find(13): 13 奇 → 父(节点6)的右
```

这不是"搜索整棵树"——递归链是一条**直链**,长度 = k 的二进制位数 = O(log n),每层 O(1)。

### 递归栈可视化(逐层展开与回退)

```text
调用阶段(压栈)                     返回阶段(弹栈,自底向上组装)
┌─ find(13)                        find(1)  → root
│  ┌─ find(6)                      find(3)  → root.right      (=节点3)
│  │  ┌─ find(3)                   find(6)  → node3.left      (=节点6)
│  │  │  ┌─ find(1) → root         find(13) → node6.right     (=节点13)
│  │  │  │  触底
```

压栈深度 = k 的二进制位数;每层栈帧记着"k 是奇还是偶",弹栈时用它选 `parent.left/right`。

### 等价的迭代写法(不习惯递归看这个)

从根开始,显式按位循环:

```java
private TreeNode findIter(int k) {
    int highBit = Integer.highestOneBit(k); // k=13 → 1000
    TreeNode node = root;
    for (int bit = highBit >> 1; bit > 0; bit >>= 1) { // 从次高位开始
        if ((k & bit) == 0) node = node.left;   // 位 0 → 左
        else                node = node.right;  // 位 1 → 右
    }
    return node;
}
```

两种写法完全等价:递归是"从下往上要父节点",迭代是"从上往下按路标走"。

## 方法②:经典队列版(队首 = 下一个插入位置)

初始化时层序遍历把**所有节点入队**,然后不断出队"左右孩子都满"的节点,队首即下一个插入位置的父节点:

- `insert`:挂到队首的空位;若占的是右位,队首使命完成出队,新节点入队尾;
- 队列中始终是"待填满的父节点候选",顺序天然符合层序。

⚠️ **常见错误**(值得单独记):初始化筛选写成

```java
while (peek().right != null) { poll(); add(peek().left); add(peek().right); }
```

有两个坑:① `left` 可能为 `null` 会把 null 入队(后续 `peek().right` NPE);② **左满右空的节点是合法候选父节点**,但它的 `right == null` 会让循环提前终止,后续整层未入队,insert 挂错父节点(官方示例 [1,2] 插 4 会返回 3 而非 2)。正确写法是"全部入队 → 双满才出队"。

# 复杂度

- 方法①:构造 O(n)(数一次节点数);**insert O(log n)**(二进制位数 = 树高);空间 O(log n) 递归栈(或迭代 O(1))。**无队列,零额外存储。**
- 方法②:构造 O(n);**insert O(1)**;空间 O(n) 队列。

调用次数少、想省内存 → ①;insert 极高频 → ②。

# 易错点

1. **队列版初始化筛选条件**(见上,原实现踩过):`right != null` 提前终止 + `add(null)` NPE,正确语义是"双满才出队"。
2. **队列版孩子入队时机**:`insert` 中**无论占左还是占右,新节点都要入队尾**——只在占右位时入队的话,后续以它为父的插入会挂错位置(占左位时新节点的空位要等两轮后才用到)。
3. **新编号 vs 旧编号**:insert 时先 `size++` 再用,**父编号 = 新编号/2**,别用自增前的 size 算。
4. **左右判定**:新编号偶 → 左,奇 → 右;与"父编号 = 新编号/2"配套,别混用两套约定。

# Code

## 解法①:位路径递归(无队列)

```Java []
class CBTInserter {
    private final TreeNode root;
    private int size; // 当前节点总数(编号 1..size)

    public CBTInserter(TreeNode root) {
        this.root = root;
        this.size = count(root);
    }

    private int count(TreeNode node) {
        if (node == null) return 0;
        return 1 + count(node.left) + count(node.right);
    }

    public int insert(int val) {
        size++;
        TreeNode parent = find(size / 2); // 新节点编号 size,父编号 size/2
        TreeNode child = new TreeNode(val);
        if (size % 2 == 0) parent.left = child;   // 偶 -> 左
        else parent.right = child;                // 奇 -> 右
        return parent.val;
    }

    /** 层序编号 k 的节点:递归到父,再按 k%2 选左/右。 */
    private TreeNode find(int k) {
        if (k == 1) return root;
        TreeNode parent = find(k / 2);
        return (k % 2 == 0) ? parent.left : parent.right;
    }

    public TreeNode get_root() { return root; }
}
```

## 解法②:经典队列版

```Java []
public class CBTInserterQueue {
    private final Deque<TreeNode> queue = new ArrayDeque<>();
    private final TreeNode root;

    public CBTInserterQueue(TreeNode root) {
        this.root = root;
        Deque<TreeNode> all = new ArrayDeque<>();
        all.add(root);
        while (!all.isEmpty()) {          // 层序:所有节点入队
            TreeNode node = all.poll();
            queue.add(node);
            if (node.left != null) all.add(node.left);
            if (node.right != null) all.add(node.right);
        }
        while (queue.peek().left != null && queue.peek().right != null) {
            queue.poll();                 // 双满才出队,队首即插入位置
        }
    }

    public int insert(int val) {
        TreeNode parent = queue.peek();
        TreeNode child = new TreeNode(val);
        queue.add(child);                 // 新节点入队尾(左右分支都要!)
        if (parent.left == null) {
            parent.left = child;          // 占左位,父仍是队首
        } else {
            parent.right = child;         // 占右位,父出队
            queue.poll();
        }
        return parent.val;
    }

    public TreeNode get_root() { return root; }
}
```
