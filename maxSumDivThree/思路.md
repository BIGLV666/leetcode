# 1262. 可被三整除的最大和（Medium）

**题目链接**: https://leetcode.cn/problems/greatest-sum-divisible-by-three/

## 核心思路

**模 3 DP** — 维护三个状态：`dp[0]`、`dp[1]`、`dp[2]` 分别表示当前子序列和 mod 3 的最大值。

1. 初始化：`dp = [0, -∞, -∞]`（空子序列和为 0，mod 1 和 mod 2 不可达）。
2. 对每个 num，计算新状态 `temp[(i + num%3) % 3] = max(旧状态, dp[i] + num)`。
3. 最终答案为 `dp[0]`。

## 状态转移

```
temp[(i + num%3) % 3] = max(
    dp[(i + num%3) % 3],   // 不选 num
    dp[i] + num             // 选 num
)
```

## 复杂度

- **时间复杂度**: O(N)。
- **空间复杂度**: O(1)，只用 3 个元素的数组。

## 易错点

1. 初始化 `dp[1]` 和 `dp[2]` 为 -1e9（或 math.MinInt），表示不可达状态。
2. 每次需要临时数组 `temp`，避免同一轮内重复使用 num。
