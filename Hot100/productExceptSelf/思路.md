# 238. 除自身以外数组的乘积（Medium）

**题目链接**: https://leetcode.cn/problems/product-of-array-except-self/

## 核心思路

**前缀积 + 后缀积** — `res[i] = nums[0..i-1] 的乘积 × nums[i+1..n-1] 的乘积`。

1. `left[i]` 表示 `nums[0..i-1]` 的前缀乘积，`left[0] = 1`（左边界哨兵）。
2. `right[i]` 表示 `nums[i..n-1]` 的后缀乘积，`right[n] = 1`（右边界哨兵）。
3. 一次循环同时计算：`left[i+1] = nums[i] * left[i]`，`right[r] = nums[r] * right[r+1]`。
4. 结果 `res[i] = left[i] * right[i+1]`。

## 为什么用前缀/后缀积？

- 不能使用除法，且希望 O(N) 时间。把"除自身以外"拆成"左边全部 × 右边全部"，用两个辅助数组 O(N) 空间即可。

## 复杂度

- **时间复杂度**: O(N)，三次线性遍历（可合并为两次）。
- **空间复杂度**: O(N)，left/right 两个辅助数组（不计返回值 res）。

## 易错点

1. **哨兵初始化**：`left[0] = 1`、`right[n] = 1`，否则边界元素计算错误。
2. **下标对齐**：`res[i] = left[i] * right[i+1]`，注意 right 偏移一位（right[i+1] 才是 `nums[i+1..n-1]` 的乘积）。
3. **含 0 的情况**：本解法天然兼容数组含 0，无需特殊处理（若用"总乘积除以自身"则需特判 0）。

## 更优解法

- **空间优化 O(1)**：先用 `res` 数组存前缀积，再从右往左用一个变量滚动维护后缀积直接乘进 `res`，省去 left/right 辅助数组。
