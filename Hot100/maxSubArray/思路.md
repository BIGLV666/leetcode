# 53. 最大子数组和（Medium）

**题目链接**: https://leetcode.cn/problems/maximum-subarray/

## 核心思路

**动态规划** — `dp[i]` 表示以 `nums[i]` 结尾的连续子数组的最大和。

1. `dp[0] = nums[0]`，初始化全局最大值 `res = dp[0]`。
2. 对每个 `i`（从 1 开始）：
   - 若 `dp[i-1] >= 0`，则 `dp[i] = dp[i-1] + nums[i]`（把前面的正贡献拼进来）。
   - 否则 `dp[i] = nums[i]`（前面的贡献为负，直接舍弃，从当前元素重新开始）。
   - 更新 `res = max(res, dp[i])`。
3. 返回 `res`。

## 为什么条件用 `>= 0` 而不是 `> 0`？

- 当 `dp[i-1] == 0` 时，拼接与否结果相同，用 `>=` 拼接进来不影响最终最大值，代码上等价。

## 复杂度

- **时间复杂度**: O(N)，单次遍历。
- **空间复杂度**: O(N)，dp 数组（可优化为 O(1)，见下）。

## 易错点

1. **空数组边界**：`dp[0] = nums[0]` 假设数组非空；若允许空数组需提前特判。
2. **负数数组**：全为负数时，`res` 应返回最大的单个负数，而非 0，故 `res` 初始化为 `dp[0]` 而非 0。

## 更优解法

- **空间优化**：只需记录前一个 `dp[i-1]`，用单个变量滚动即可，空间复杂度降为 O(1)。
- **分治法**：线段树思想，可支持区间查询，但本题没必要，DP 已是最简。
