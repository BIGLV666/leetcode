# 思路

> 你选用何种方法解题？

幂集有 **2^n** 个子集(每个元素独立地「选 / 不选」),所以任何解法的输出规模注定是指数级。两种经典构造方式,本文各给一版实现:

| 方法 | 视角 | 关键机制 |
|------|------|----------|
| ① 二叉决策回溯 | 逐元素做"选/不选"的**二元决策** | 递归树 2^n 个叶子 = 2^n 个子集,天然不重不漏 |
| ② 增量构造(非回溯) | 从空集出发,新元素让子集数**翻倍** | 每层把已有子集复制一份追加新元素 |

两者都是 O(n·2^n) 时间;回溯版额外空间 O(n)(递归栈+路径),增量版输出即 O(n·2^n)、额外 O(1)。

# 解题过程

> 这些方法具体怎么运用？

## 方法①:二叉决策回溯

对下标 `c` 递归,每次做两个决策:选 `nums[c]` / 不选 `nums[c]`;`c == n` 时路径 `t` 就是一个完整子集。

以 `nums = [1,2,3]` 为例,**递归树**(左枝=选,右枝=不选,叶子上标注进入叶子时的路径):

```text
                        dfs(0) t=[]
                       /              \
                 选1  /                \  不选1
                     /                  \
              dfs(1) t=[1]            dfs(1) t=[]
              /          \             /          \
        选2  /            \ 不选2  选2  /            \ 不选2
            /              \         /              \
    dfs(2) t=[1,2]   dfs(2) t=[1]   dfs(2) t=[2]    dfs(2) t=[]
      /       \        /      \       /      \        /      \
  选3      不选3   选3     不选3  选3     不选3   选3     不选3
    |         |       |        |      |        |       |       |
dfs(3)     dfs(3)  dfs(3)   dfs(3) dfs(3)  dfs(3)  dfs(3)  dfs(3)
t=[1,2,3]  t=[1,2] t=[1,3]  t=[1]  t=[2,3]  t=[2]   t=[3]   t=[]
   ✅叶       ✅叶    ✅叶      ✅叶    ✅叶     ✅叶    ✅叶     ✅叶
```

8 个叶子恰好对应 8 个子集,**顺序为 `[1,2,3], [1,2], [1,3], [1], [2,3], [2], [3], []`**——正是先选后不选时叶子被收集的自然顺序。

### 递归栈的展开(只跟踪最左一条链)

进入 `dfs(0)` 后一路"选",栈内容与路径同步变化:

```text
dfs(0) t=[]
 │ add(1)                    ← 先做"选 1"决策
 ├─ dfs(1) t=[1]
 │  │ add(2)
 │  ├─ dfs(2) t=[1,2]
 │  │  │ add(3)
 │  │  ├─ dfs(3) t=[1,2,3]   ← c==n,拷贝 t 进 res(不能直接放 t 的引用!)
 │  │  │  return
 │  │  │ removeLast()        ← 回溯:撤销"选 3",t 恢复 [1,2]
 │  │  ├─ dfs(3) t=[1,2]     ← "不选 3"分支,拷贝 [1,2]
 │  │  │  return
 │  │  └─ return
 │  │ removeLast()           ← 撤销"选 2",t 恢复 [1]
 │  ├─ dfs(2) t=[1]          … 后续同理
```

要点:

- **每层栈帧记得自己的 `c`**,返回时自然回到上一层;`t` 是共享的可变对象,**进入子调用前 add、回来后 removeLast** 保证"现场恢复";
- `res.add(new ArrayList<>(t))` 必须**拷贝**——直接放 `t` 的引用的话,之后所有回溯修改都会污染已收集的结果(高频错误);
- 树的每条根到叶路径对应一个子集,2^n 条路径 ↔ 2^n 个子集,不重不漏。

## 方法②:增量构造(不回溯,双层循环)

从 `[[]]` 出发,处理第 i 个元素 `x` 时:**复制当前结果里每个子集,追加 x,作为新增子集**。处理完 i 个元素后恰好 2^i 个子集。

`nums = [1,2,3]` 的演进过程:

```text
初始           : []
处理 1         : [] | [1]
处理 2         : [] [1] | [2] [1,2]
处理 3         : [] [1] [2] [1,2] | [3] [1,3] [2,3] [1,2,3]
                   ↑旧子集(不含3)      ↑每个旧子集复制并追加 3
```

**最关键的坑**:内层循环必须以进入时的 `int size = res.size()` 为上界。若写成 `i < res.size()`,本轮新追加的子集会被继续遍历、再复制追加 x——子集无限翻倍,死循环。

这个方法还有个直觉解释:第 i 轮把所有子集分成"含 x / 不含 x"两半,新增的一半是旧子集与 `{x}` 的笛卡尔积。

## Python 版同样适用(注意键类型)

Python 里 `res[i] + [x]` 天然生成新列表,不需要手动复制,一行即成:

```python []
def subsets(self, nums: List[int]) -> List[List[int]]:
    res = [[]]
    for x in nums:
        size = len(res)                # 快照!
        for i in range(size):
            res.append(res[i] + [x])
    return res
```

# 复杂度

- 时间复杂度: $O(n \cdot 2^n)$ —— 两种方法都输出 $2^n$ 个子集,单个子集构造/拷贝代价 $O(n)$。
- 空间复杂度: $O(n)$(回溯:递归栈 + 路径,不计输出)/ $O(n \cdot 2^n)$(增量:结果集本身;额外辅助 $O(1)$)。

# 易错点

1. **回溯版忘记拷贝**:`res.add(t)` 收集的是引用,后续回溯会把所有已收集子集改得面目全非(通常表现为结果全是空集或全是同一个子集)。
2. **回溯顺序**:先 `add → dfs → removeLast → dfs`;把"不选"放在撤销之前,路径状态就乱了。
3. **增量版内层上界**:必须用 `size` 快照,`res.size()` 会把本轮新增也遍历进去。
4. **幂集必须含空集**:回溯版由"全不选"叶子天然给出;增量版必须手动以 `[[]]` 为种子。

# Code

## 回溯版

```Java []
class Solution {
    private List<List<Integer>> res ;
    private List<Integer>t; // 当前路径:已做出决策的前缀
    public List<List<Integer>> subsets(int[] nums) {
        res = new ArrayList<>();
        t=new ArrayList<>();
        dfs(0,nums);
        return res;
    }

    /** 决策下标 c:选 nums[c] 走左枝,回溯后不选走右枝;c==n 时路径即一个子集。 */
    public void dfs(int c,int []nums){
        if(c==nums.length){
            res.add(new ArrayList<>(t)); // 必须拷贝:t 还会被后续回溯修改
            return;
        }
        t.add(nums[c]);   // 决策一:选
        dfs(c+1,nums);
        t.removeLast();   // 回溯撤销,恢复现场
        dfs(c+1,nums);    // 决策二:不选
    }
}
```

## 增量构造版(不回溯,双层循环)

```Java []
public class SubsetsIterative {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        res.add(new ArrayList<>()); // 空集是幂集的一员,也是增量构造的种子
        for (int x : nums) {                 // 外层:逐个引入元素
            int size = res.size();           // 快照!只扩展"不含 x 的旧子集"
            for (int i = 0; i < size; i++) {
                List<Integer> next = new ArrayList<>(res.get(i)); // 复制旧子集
                next.add(x);                 // 追加 x → 新子集
                res.add(next);
            }
        }
        return res;
    }
}
```
