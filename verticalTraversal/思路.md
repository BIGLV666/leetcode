> Problem: [987. 二叉树的垂序遍历](https://leetcode.cn/problems/vertical-order-traversal-of-a-binary-tree/description/)

[TOC]

# 思路



>**坐标建模 + 哈希分组 + 多级排序**。

先把整棵树映射到平面坐标系上:

- 根节点位于 `(row=0, col=0)`;
- 左孩子是 `(row+1, col-1)`,右孩子是 `(row+1, col+1)`(行向下递增,列向左减右增)。

题目要求的输出顺序,本质就是对该坐标系的三级排序:

1. 同一列(`col` 相同)的节点放一组,组与组按 `col` **从小到大**(从左到右);
2. 同组内按 `row` **从小到大**(自顶向下);
3. 同行同列(`row`、`col` 都相同,必然分别来自左右子树)按节点值 `val` **升序**。

于是问题转化为:BFS/DFS 收集所有节点 → 按 `col` 分桶 → 排序输出。

# 解题过程



>1. **包装节点**:定义 `Node` 把原树节点的 `val` 与坐标 `(row, col)` 拷贝一份,同时保留左右孩子引用,供 BFS 展开(避免在原树上挂额外字段)。
>2. **BFS 收集**:从根 `(0,0)` 开始层序遍历;每展开一个孩子就计算其坐标,追加到哈希表 `table[col]` 对应的列列表中。BFS 天然按行递增访问,但同列内的次序还不能直接用,需要最后统一排序。
>3. **按列排序**:`sorted(table.items())` 得到"从左到右"的列顺序。**注意 dict 不保序**,这一步不能省——否则输出顺序是列的插入顺序而不是列号顺序。
>4. **组内排序**:每列按元组键 `(row, val)` 排序,一次完成"自顶向下 + 同行按值"的双重语义,比手写 `cmp_to_key` 简洁。
>5. **提取输出**:把排好序的节点列表映射成值列表 `res`,即最终答案。

# 复杂度

- 时间复杂度: $O(n \log n)$ —— BFS 收集是 $O(n)$;设各列节点数为 $k_c$,组内排序代价为 $\sum k_c \log k_c \le n \log n$,列排序 $O(c \log c)$($c$ 为列数,$\le n$),总体由排序主导。
- 空间复杂度: $O(n)$ —— 哈希表与包装节点各存 $n$ 份。

# Code

```Python3 []
class Node:
    """包装层序节点:携带值与 (row, col) 坐标,保留孩子引用供 BFS 展开。"""

    def __init__(self, root: TreeNode, row, col):
        self.val = root.val
        self.row = row
        self.col = col
        self.left = root.left
        self.right = root.right


class Solution:
    """987. 二叉树的垂序遍历

    坐标:根为 (row=0, col=0),左孩子 (row+1, col-1),右孩子 (row+1, col+1)。
    按 col 从左到右输出每列;同列内按 row 自顶向下;同行同列再按 val 升序。

    解法:BFS 逐层收集到「列号 -> 节点列表」哈希表,最后按列号排序、
    组内按 (row, val) 排序输出。
    复杂度:时间 O(n log n)(排序主导),空间 O(n)。
    """

    def verticalTraversal(self, root: Optional[TreeNode]) -> List[List[int]]:
        root_node = Node(root, 0, 0)
        table = dict()  # 列号 -> 该列节点列表(收集顺序无序,输出前必须排序)
        table[0] = [root_node]
        dq = deque()
        dq.append(root_node)
        while dq:
            node = dq.popleft()
            if node.left:
                left_node = Node(node.left, node.row + 1, node.col - 1)
                dq.append(left_node)
                if left_node.col not in table:
                    table[left_node.col] = [left_node]
                else:
                    temp = table[left_node.col]
                    temp.append(left_node)
            if node.right:
                right_node = Node(node.right, node.row + 1, node.col + 1)
                dq.append(right_node)
                if right_node.col not in table:
                    table[right_node.col] = [right_node]
                else:
                    temp = table[right_node.col]
                    temp.append(right_node)
        # dict 不保序:按列号升序整理出"从左到右"的列顺序
        temp = sorted(table.items())
        res = []
        for _, v in temp:
            # 同列内:行号升序(自顶向下),同行同列再按值升序 —— 元组 key 一次搞定
            v.sort(key=lambda x: (x.row, x.val))
            res.append([x.val for x in v])
        return res



```
