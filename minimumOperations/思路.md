# 2471. 逐层排序二叉树所需的最少操作数目

## 题目描述

给你一棵二叉树的根节点 `root`,树中每个节点的值互不相同。

一次操作:选择**同一层**中的任意两个节点,交换它们的值。

要求让每一层的节点值都按**从左到右严格递增**的顺序排列,返回所需的**最少操作次数**。

题目链接:[2471. 逐层排序二叉树所需的最少操作数目](https://leetcode.cn/problems/minimum-number-of-operations-to-sort-a-binary-tree-by-level/description/)

### 示例

```text
输入:root = [1,4,3,7,6,8,5,null,null,null,null,9,null,10]
输出:3
```

对应的树结构如下:

```text
           1
          / \
         4   3
        / \ / \
       7  6 8  5
      /        /
     9        10
```

逐层分析:

```text
第 0 层:[1]             已有序,0 次
第 1 层:[4,3]           1 次
第 2 层:[7,6,8,5]       2 次
第 3 层:[9,10]          已有序,0 次
总计:1 + 2 = 3
```

---

## 思路

题目的操作只能在同一层内进行,因此**不同层之间完全独立**:把每一层单独排序,所需操作数互不影响,总答案就是把每层的最小操作数累加。

于是问题被拆成两个子问题:

```text
① 分层:把二叉树按层压缩成若干个数组;
② 对每个数组,求「允许交换任意两个元素」时的最少交换次数。
```

第一问用 BFS 层序遍历即可。关键在第二问。

---

## 核心结论:最少交换次数 = n - 循环节个数

把当前层的值记为一个数组 `nums`。排序后的目标数组记作 `sorted`。

由于每个节点的值互不相同,可以给每个值确定它**唯一的目标位置**:

```text
pos[value] = value 在 sorted 中的下标
```

这样 `nums` 就对应一个置换(permutation):位置 `i` 上的值最终要去位置 `pos[nums[i]]`。

沿着这个置换走,会得到若干个**循环节**(环):

```text
i -> pos[nums[i]] -> pos[nums[  pos[nums[i]]  ]] -> ... -> 回到 i
```

结论:

```text
一个长度为 L 的循环节,最少需要 L - 1 次交换才能排好。
```

所以若总长度为 `n`、循环节个数为 `loops`,则:

```text
最少交换次数 = Σ (L_k - 1) = n - loops
```

### 为什么一个长度为 L 的环需要 L - 1 次交换?

- **下界**:环上 `L` 个元素都在别人的位置上(每个都不在自己应在的位置)。一次交换最多让一个元素归位,因此至少要 `L - 1` 次。
- **可达**:每次把「位置 `i` 上的元素」与「它应该在的位置 `pos[nums[i]]` 上的元素」交换,就能让一个元素归位,并让环长减 1。重复 `L - 1` 次后环消解。

因此 `L - 1` 既是下界又能达到,最小值为 `L - 1`。

而已经就位的元素自身构成长度为 1 的环,贡献 `1 - 1 = 0`,不影响结果。

### 注意:这里是「任意交换」而不是「相邻交换」

题目允许交换同一层中**任意**两个节点,所以:

```text
最少交换次数 = n - 循环节个数
```

如果题目改成「只能交换相邻元素」,答案将变成**逆序对个数**,两者完全不同。读题时务必确认交换的粒度。

## 算法流程

### 1. BFS 分层

用队列逐层遍历,每层收集成一个 `List<Integer>`:

```java
Deque<TreeNode> queue = new ArrayDeque<>();
queue.push(root);
while (!queue.isEmpty()) {
    int len = queue.size();          // 当前层的节点数
    List<Integer> level = new ArrayList<>();
    for (int i = 0; i < len; i++) {
        TreeNode node = queue.pollFirst();
        if (node.left != null) queue.addLast(node.left);
        if (node.right != null) queue.addLast(node.right);
        level.add(node.val);
    }
    res.add(level);
}
```

`len = queue.size()` 在进入内层循环前固定下来,是分层的关键:它保证这一轮只处理当前层的节点,新加入的孩子留到下一轮。

### 2. 对每层求最少交换次数

```java
private int f(List<Integer> list) {
    int len = list.size();
    int[] nums = list.stream().mapToInt(Integer::intValue).toArray();
    int[] sorted = nums.clone();
    Arrays.sort(sorted);

    // value -> 目标位置
    Map<Integer, Integer> pos = new HashMap<>();
    for (int i = 0; i < sorted.length; i++) {
        pos.put(sorted[i], i);
    }

    boolean[] vis = new boolean[len];
    int loops = 0;
    for (int i = 0; i < len; i++) {
        if (!vis[i]) {
            int j = i;
            while (!vis[j]) {
                vis[j] = true;
                j = pos.get(nums[j]);   // 跳到「当前元素该去的位置」
            }
            loops++;                    // 走完一个循环节
        }
    }
    return len - loops;
}
```

要点:

- 用 `vis` 数组标记访问过的**位置**,保证每个位置只被一个环统计一次。
- `j = pos.get(nums[j])` 是环上「下一个位置」的求法:`nums[j]` 是当前位置的值,`pos` 告诉它该去哪个位置。
- 每发现一个环,`loops++`;最终答案 `len - loops`。

### 3. 累加各层答案

```java
int ans = 0;
for (List<Integer> level : res) {
    ans += f(level);
}
return ans;
```

## 正确性分析

### 1. 层与层相互独立

一次操作只在同一层内交换两个值,不会改变任何节点的层号,也不会把值搬到别的层。因此某一层的排列状态不受其他层操作的影响。各层的最优解可以直接相加得到全局最优解。

### 2. 置换的循环分解是唯一的

`pos` 由「值 → 排序后位置」唯一确定,因此每个位置的后继唯一,环路分解唯一。`vis` 数组确保每个环恰好被统计一次。

### 3. `n - loops` 就是该层的最小操作数

由前面的下界与构造可知,每个长度 `L` 的环恰好需要 `L-1` 次,累加得 `n - loops`,且可构造达到。

### 4. 已就位的元素不产生开销

排好序后数据满足 `nums[i] == sorted[i]`,此时 `pos[nums[i]] == i`,每个元素自成一个长度 1 的环,贡献 0。整层有序时 `loops == len`,返回 `len - len = 0`。

## 复杂度分析

设二叉树节点数为 `n`,第 `k` 层节点数为 `n_k`,最大层大小为 `m`。

### 时间复杂度

- BFS 分层:每个节点进出队列一次,`O(n)`。
- 单层:复制与排序 `O(n_k log n_k)`,求环 `O(n_k)`。
- 求和:`Σ n_k log n_k ≤ n log m`。

整体:

```text
O(n log m)
```

最坏(链式树)时每层只有 1 个节点,退化为 `O(n)`;最坏(满二叉树底层的层)为 `O(n log n)`。

### 空间复杂度

- 分层结果与队列:`O(n)`。
- 每层排序副本与 `pos` 映射、`vis` 数组:`O(m)`。

整体额外空间:

```text
O(n)
```

## 易错点

### 1. 误当成「相邻交换」

本题可交换同一层任意两个节点,答案是 `n - 循环节个数`。若按相邻交换去数逆序对,示例 1 会得到错误答案。**先确认交换的粒度**。

### 2. 分层时忘记固定当前层长度

错误写法:

```java
while (!queue.isEmpty()) {
    // 没有提前记录 len,边遍历边入队会把下一层节点混进当前层
    TreeNode node = queue.poll();
    ...
}
```

必须在进入内层循环前用 `int len = queue.size()` 锁定当前层。

### 3. 把「值」当作环上的节点

环是作用在**位置**上的:`j = pos.get(nums[j])` 返回的是位置。用 `vis[j]` 标记位置,而不是标记值,否则会重复计数或跳过。

### 4. 忽略了值的唯一性

`value -> 目标位置` 的映射依赖「每个值互不相同」。题目保证值互异,因此 `HashMap` 不会发生覆盖;若值可重复,则需改用「值 + 出现顺序」等其他建模方式。

### 5. 单层只有 1 个节点时也要能正常返回 0

此时 `loops == 1`,`len - loops == 0`,逻辑天然正确。链式树会大量出现这种情况。

---

## 总结

整道题的骨架可以概括为:

```text
BFS 分层
   ↓
每层:值数组 → 目标位置映射 → 数循环节个数 loops
   ↓
该层代价 = 层大小 - loops
   ↓
全部累加
```

真正的难点不在树的遍历,而在第二步的转化:把「同一层内任意两节点交换」的最少次数,转成置换的循环分解。记住结论:

```text
允许任意交换时,把序列排序的最少交换次数 = n - 循环节个数
```

时间复杂度 `O(n log m)`,空间复杂度 `O(n)`。
