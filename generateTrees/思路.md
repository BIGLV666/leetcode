# 思路

> 你选用何种方法解题？

两个思路,**分治构造是正解,排列枚举 + 去重是帮助理解"为什么会重复"的铺垫**:

| 方法 | 机制 | 复杂度 | 去重 |
|------|------|--------|------|
| ① 排列枚举 + 结构签名 | n! 个插入序列逐个建 BST,事后去重 | O(n!·n) | 需要签名 |
| ② 分治构造 | 根 × 左子树集合 × 右子树集合 的笛卡尔积 | O(Catalan(n)·n) ≈ O(4ⁿ/n) | **生成即唯一,不需要** |

关键观察:**BST 由「根值 + 左子树形态 + 右子树形态」唯一确定**——这就是分治的立足点。

# 解题过程

> 这些方法具体怎么运用？

## 方法①:排列枚举 + 结构签名去重(先想错,再想对)

朴素直觉:n 个数有 n! 种插入次序,全部试一遍不就得到所有 BST?

跑一遍 n=3 就会发现 6 个排列只出 **5 棵**树——`(2,1,3)` 和 `(2,3,1)` 的首元素相同、都先建根 2,左右孩子也相同,**殊途同归**:

```text
(2,1,3): 先插2,再插1(左),再插3(右)     (2,3,1): 先插2,再插3(右),再插1(左)
      2                                      2
     / \                                    / \
    1   3                                  1   3
         完全相同的结构,插入次序在子树内部不可区分
```

所以需要**结构签名**去重:递归返回 `(val, 左签名, 右签名)` 嵌套元组——元组可哈希(对比:直接拿 list 当 dict 键会抛 `unhashable type`),进 set 判重即可。**为什么不能用节点对象身份 `is` 去重**:同构的两棵树是不同对象,身份必不同;必须按内容签名。

## 方法②:分治构造(正解)

把"生成 [lo, hi] 的所有 BST"分解为:

1. **枚举根**:区间内每个值 `i` 都当一次根(共 hi−lo+1 种);
2. **分治子问题**:左子树 = `build(lo, i-1)` 的所有形态,右子树 = `build(i+1, hi)` 的所有形态——结构与原问题完全相同,只是值域变小;
3. **笛卡尔积组合**:每种 (左, 右) 组合配 `TreeNode(i, L, R)`;
4. **递归基**:空区间返回 `[None]`(空树),保证叶节点也能参与组合。

**为什么天然无重复**:不同的 `i` → 根值不同 → 整棵树必不同;相同的 `i` → 左右来自"自身已无重复"的递归集合,笛卡尔积两两不同。**重复在生成源头被消灭**。

n=3 的完整推演:

```text
根=1: 左 build(1,0)=[None] × 右 build(2,3) 的 2 种  → [1,null,2,null,3], [1,null,3,2]
根=2: 左 build(1,1)={1}     × 右 build(3,3) 的 1 种  → [2,1,3]
根=3: 左 build(1,2) 的 2 种 × 右 build(4,3)=[None]  → [3,1,null,null,2], [3,2,null,1]
                                                 合计 5 = Catalan(3)
```

数量恰为卡特兰数 `Catalan(n) = C(2n,n)/(n+1)`:1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862 …(LC 96 就是只求数量的版本)。

## 性能对比(为什么②是正解)

n=10:排列法要处理 10! = 3,628,800 个序列,每个插入 O(n) ≈ **3.6×10⁷ 步** + 去重;分治法只构造 4862 棵有效树 ≈ **10⁵ 级节点操作**。**三个数量级的差距**,n 越大越悬殊。

# 复杂度

- 时间复杂度: ① $O(n! \cdot n)$(n! 个排列 × 插入与签名);② $O(\text{Catalan}(n) \cdot n) \approx O(4^n / n)$(只构造有效树,每棵 O(n),含记忆化)。
- 空间复杂度: ① $O(n!)$ 存排列 + 去重集合;② $O(n)$ 递归栈 + 记忆化(输出本身 $O(n \cdot \text{Catalan}(n))$ 不计)。

# 易错点

1. **同签名 ≠ 同对象**:去重必须按**内容**(签名/序列化),不能用节点 `is` 身份——同构树必是不同对象。
2. **签名要用嵌套元组**:`(val, 左, 右)` 递归定义;直接拿 list 当 dict 键会 `unhashable type: 'list'`(list 可变不可哈希,tuple 才行)。
3. **分治基例**:`lo > hi` 返回 `[None]` 而不是 `[]`——空树也是一个"形态",否则叶节点组合不出任何树。
4. **n=0**:LC 约定返回 `[]`(不是 `[None]` / `[[]]`),两版都要单独处理。
5. **重复定义方法**:`class` 里同名方法后者覆盖前者(Python 不报错),两版解法要放两个类。

# Code

## 解法①:排列枚举 + 结构签名去重

```Python []
class Solution:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        if n == 0:
            return []
        res = list(permutations(range(1, n + 1)))
        seen = set()
        ans = []
        for nums in res:
            root = None
            for i in range(n):
                root = self.dfs(nums[i], root)
            sig = self.sig(root)
            if sig not in seen:
                seen.add(sig)
                ans.append(root)
        return ans

    def dfs(self, val, root):
        if root is None:
            return TreeNode(val)
        if val < root.val:
            root.left = self.dfs(val, root.left)
        else:
            root.right = self.dfs(val, root.right)
        return root

    def sig(self, node):
        if node is None:
            return None
        return (node.val, self.sig(node.left), self.sig(node.right))
```

## 解法②:分治构造(推荐)

```Python []
class SolutionDivide:
    def generateTrees(self, n: int) -> List[Optional[TreeNode]]:
        def build(lo, hi):
            if lo > hi:
                return [None]          # 空区间 -> 空树,保证叶级可组合
            if (lo, hi) in memo:
                return memo[(lo, hi)]
            res = []
            for root_val in range(lo, hi + 1):
                for L in build(lo, root_val - 1):
                    for R in build(root_val + 1, hi):
                        res.append(TreeNode(root_val, L, R))
            memo[(lo, hi)] = res
            return res

        memo = {}
        return build(1, n) if n else []
```
