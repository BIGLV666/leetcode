# 825. 适龄的朋友（Medium）

**题目链接**: https://leetcode.cn/problems/friends-of-appropriate-ages/

## 核心思路

**排序 + 二分查找** — 将年龄数组排序后，对每个人 x 二分查找满足条件的朋友范围。

1. 将年龄数组排序。
2. 对每个人 x（年龄 ages[x]）：
    - 计算 `minAge = ages[x] / 2 + 7`（条件：ages[y] > minAge）。
    - 若 `ages[x] ≤ minAge`，该人不可能交到朋友，跳过。
    - 二分查找：`lo` = 第一个 `> minAge` 的位置，`hi` = 第一个 `> ages[x]` 的位置。
    - 满足条件的人数 = `hi - lo - 1`（减 1 排除自己）。
3. 累加结果。

## 朋友条件

y 可以向 x 发送好友请求需同时满足：

- `ages[y] > ages[x] / 2 + 7`
- `ages[y] ≤ ages[x]`
- `!(ages[y] > 100 && ages[x] < 100)`

第三条条件等价于 `ages[y] ≤ 100 || ages[x] ≥ 100`，在已排序的条件下，`ages[y] ≤ ages[x]` 已覆盖大部分情况。实际中第三条条件很少触发。

## 复杂度

- **时间复杂度**: O (N log N)，排序 + N 次二分查找。
- **空间复杂度**: O (1)（原地排序）。

## 易错点

1. 二分查找"第一个 > target"用 `arr[mid] > target` 判断，相等时继续向右移。
2. 结果要减 1（排除自己），需确保 `hi - lo - 1 ≥ 0`。
3. `ages[x] ≤ minAge` 时直接跳过（条件 `ages[x]/2+7 ≥ ages[x]` ⇒ ages[x] ≤ 14，14 岁以下无人可交朋友）。
